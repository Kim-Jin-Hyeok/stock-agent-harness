# KIS 종목 자격 대체 원천 검증

## 결론과 범위

2026-10-06 KIS 공식 주식기본조회 규격에서 시장, 증권 그룹과 보통주·우선주 코드 정의를 확보했다. 기존 KIS 마스터에서도 SPAC·관리종목·코스닥 투자주의환기 원문을 확인했다. **KIS만으로 현재 종목 정보를 보완할 경로는 확인했지만, 실제 주식기본조회 응답과 운영 자격 연결은 아직 검증하지 않았다.**

주식기본조회는 공식 규격상 **모의투자 미지원**이다. 로컬 `.env`에는 모의 키만 있어 종목 조회와 토큰 발급을 수행하지 않았다. 실패가 예상되는 모의 요청이나 실전 서버 자동 전환 대신, 실측에 필요한 실전 조회 자격 증명을 별도 준비 조건으로 남겼다. 이 제한은 KIS에 해당 데이터가 없다는 뜻이 아니다.

KIS·KRX 제한 관측 통합은 보류한다. 기존 KRX 연구 결과는 보존하되 운영 후보 선정의 필수 출처로 확정하지 않는다. `DESIGN_ONLY`, `runtimeSelectionImplemented=false`, `eligibilityOrHistoricalPopulationVerified=false`를 유지한다. 현재 마스터와 API 규격은 과거 전체 시장 모집단이나 당시 정보 가용성을 증명하지 않는다.

## 공식 주식기본조회 규격

대상은 [KIS 주식기본조회 문서](https://apiportal.koreainvestment.com/apiservice-apiservice?/uapi/domestic-stock/v1/quotations/search-stock-info)다. 공개 페이지의 상세 JSON 조회 경로를 확인하고 [공식 상세 규격](https://apiportal.koreainvestment.com/api/apis/public/detail?accessUrl=%2Fuapi%2Fdomestic-stock%2Fv1%2Fquotations%2Fsearch-stock-info)을 원문으로 보존했다. 페이지 HTML만으로 응답 필드 정의를 확인한 것으로 취급하지 않는다.

| 항목 | 규격 |
| --- | --- |
| Method / Path | `GET /uapi/domestic-stock/v1/quotations/search-stock-info` |
| 실전 Domain / TR ID | `https://openapi.koreainvestment.com:9443` / `CTPF1002R` |
| 모의 Domain / TR ID | 모두 `모의투자 미지원` |
| `PRDT_TYPE_CD` | `300`은 주식·ETF·ETN·ELW를 포함하며 개별주 자격을 보장하지 않는다. |
| `PDNO` | 종목번호. 규격은 ETN의 `Q` 접두 사례도 설명한다. 숫자 6자리만으로 유형을 판단하지 않는다. |

다음은 공개 상세 규격에서 확인한 **코드 정의**다. 실제 응답 관측이나 전체 조합의 허용 여부 판정은 아니다.

| 필드 | 확인한 정의 | 사용 시 경계 |
| --- | --- | --- |
| `mket_id_cd` | `STK`: 유가증권, `KSQ`: 코스닥, `KNX`: 코넥스 등 | KRX/NXT 거래소 구분이나 현재가 요청의 `J/NX/UN`과 혼용하지 않는다. |
| `scty_grp_id_cd` | `ST`: 주권, `EF`: ETF, `EN`: ETN, `FE`: 해외ETF 등 | `ST`만으로 보통주·우선주·SPAC 여부를 모두 판정하지 않는다. |
| `stck_kind_cd` | `101`: 보통주, `201`~`220`: 우선주 계열, `000`: 해당사항없음, `301`: 후배주, `401`: 혼합주 | `000`·공백·미정의 값은 보통주로 바꾸지 않는다. 다른 필드와의 불일치도 확인해야 한다. |
| `std_pdno`, `pdno` | 표준상품번호와 상품번호 | 요청 코드 및 마스터의 표준코드와 일치하는지 실측에서 확인한다. |
| 시장별 상장·상장폐지일, `lstg_abol_dt` | 날짜 필드 존재 | 공백·제로 날짜 등의 의미는 별도 확인이 필요하다. 현재 응답을 과거 시점 상태로 소급하지 않는다. |
| `tr_stop_yn`, `admn_item_yn` | 거래정지·관리종목 필드 존재 | 설명란은 공백이므로 실제 표현과 적용 시점은 미확인이다. 원문을 보존한다. |
| `nxt_tr_stop_yn` | NXT 거래종목 중 정지이면 `Y`, 그 외 모두 `N` | `N`이 NXT 거래 대상이라는 뜻은 아니다. KRX 거래정지와도 합치지 않는다. |
| `etf_dvsn_cd` | ETF구분코드 필드 존재 | 이번 규격의 설명란만으로 값별 의미를 확정하지 않는다. |

공식 API 응답의 `stck_kind_cd` 정의를 기존 MST의 `prst_cls_code`나 ETP 공백 정의로 소급 적용하지 않는다. 기존 [마스터 유형 매핑 보류](stock-master-type-mapping-validation-01.md)는 유지한다.

## 마스터에서 확보 가능한 제한 정보

대상은 기존 배치 `4ebd57c2-dd69-4b99-86c7-8efed3e531f7`의 KOSPI 2,578행·KOSDAQ 1,825행이다. MST를 다시 다운로드하지 않았다. [고정한 공식 규격과 예제](stock-master-type-mapping-validation-01.md)의 필드 폭으로 바이트 위치를 계산하고 전체 4,403행을 읽었다.

| 원문 필드 | KOSPI `Y` / `N` | KOSDAQ `Y` / `N` | 판정 범위 |
| --- | --- | --- | --- |
| `etpr_undt_objt_co_yn` SPAC | 0 / 2,578 | 71 / 1,754 | 현재 보존 파일의 원문 관측 |
| `mang_issu_yn` 관리종목 | 47 / 2,531 | 136 / 1,689 | 현재 보존 파일의 원문 관측 |
| `invt_alrm_yn` 투자주의환기 | 필드 없음 | 87 / 1,738 | 코스닥 필드. 코스피 미제공을 `N`으로 치환하지 않는다. |
| `trht_yn` 거래정지 | 41 / 2,537 | 85 / 1,740 | 기존 거래정지 관측 건수와 일치 |
| `sltr_yn` 정리매매 | 3 / 2,575 | 7 / 1,818 | 기존 정리매매 관측 건수와 일치 |

여러 제한이 같은 행에 겹칠 수 있으므로 각 `Y` 건수를 서로 다른 종목 수로 합산하지 않는다. 이 파일에서 `Y/N`만 관측됐다는 사실로 이후 파일의 공백·새 코드를 정상 처리하지 않는다.

SPAC·관리종목·투자주의환기의 KIS 원문 관측 건수는 [KRX 소속부 관측](../krx-stock-section-restriction.md)의 건수와 다르다. KIS 4,403행과 KRX 2,766행의 모집단, KIS 수집 시각과 KRX 요청 기준일, 제공 필드의 의미가 같다고 확인하지 않았으므로 단순 건수 차이를 원천 오류나 우선순위 규칙으로 해석하지 않는다. 같은 종목과 시점의 정의를 확인하기 전까지 양쪽 관측을 덮어쓰거나 하나의 정상 여부로 합치지 않는다.

## 실측 계획과 중단 결과

기존 마스터 원문 기준으로 다음 10개 사례를 선정했다. 이름으로 유형을 판정하지 않았으며, 사례 이름은 기대한 API 결과가 아니라 조회 전에 고정한 원문 선택 기준이다.

| 원문 선택 기준 | 시장 | 종목 코드 | 보존 원문 이름 |
| --- | --- | --- | --- |
| `ST/SPACE/0` | KOSPI | `005930` | 삼성전자 |
| `ST/SPACE/0` | KOSDAQ | `000250` | 삼천당제약 |
| `ST/SPACE/1` | KOSPI | `005935` | 삼성전자우 |
| `ST/SPACE/2` | KOSPI | `000087` | 하이트진로2우B |
| `EF/2/0` | KOSPI | `069500` | KODEX 200 |
| SPAC 원문 `Y` | KOSDAQ | `0004Y0` | 디비금융제14호스팩 |
| 관리종목 원문 `Y` | KOSPI | `000040` | KR모터스 |
| 투자주의환기 원문 `Y` | KOSDAQ | `007330` | 푸른저축은행 |

| 정리매매 원문 `Y` | KOSDAQ | `067770` | 세진티에스 |

계획의 상한은 종목 조회 10회·토큰 발급 1회이며 자동 재시도·연속 페이지·실전 fallback은 금지한다. 실제 결과는 `OFFICIAL_SPECIFICATION_PAPER_UNSUPPORTED`로 10개 모두 미요청이다. **토큰·종목·계좌·주문·KRX 요청은 모두 0회**다. 공식 자료 보존 헬퍼의 공개 HTTP 요청 4회와 별도 페이지 탐색·웹 열람은 Broker 실측 횟수가 아니다.

실측은 실전용 자격 증명을 로컬에서 별도로 준비하고, 실전 종목정보 조회 범위를 명시한 새 관측으로 수행해야 한다. 키·secret·토큰을 채팅·로그·Git 증적에 담지 않는다. `KIS_READONLY_APP_KEY` 같은 로컬 변수명은 검증 도구의 용도 표시일 뿐 증권사가 읽기 전용 권한을 부여했다는 뜻은 아니다. 도구에서 종목정보·토큰 경로만 허용하고 계좌·주문 경로를 차단해야 한다.

실측 시 요청 종목·표준코드·시장·유형·제한 값을 원문과 대조하고, 누락·미정의 값·불일치·API 실패를 보존한다. 서로 다른 날짜의 상태 차이는 곧바로 오류로 판정하지 않는다. 일부 샘플 성공도 전시장 전체 범위나 과거 자격 검증으로 확대하지 않는다.

## 보존과 재현

증적과 임시 PowerShell 도구는 Git 제외 경로 `build/kis-stock-eligibility-source-validation-01/`에 있다. 운영 Java 패키지에 새 클래스를 추가하지 않았다.

| 보존 파일 | SHA-256 |
| --- | --- |
| 공식 상세 규격 `apiportal-specification.json` | `1fbf349c755a3f54469450e0b7ca89ee3aa3a779e4a33286348cc2e198c0567a` |
| 고정 예제 `search_stock_info.py` | `342e0be8577953b1c7c444a084045c3b07ad4b1b49334f948e3ff0472dfe9bf8` |
| 고정 예제 `chk_search_stock_info.py` | `690569b0f93fec528200a5eab21a297a2f32ff2b132503ba6035ca1d7594f284` |
| 최초 로컬 검증 `verification.json` | `9d5c0006089fd58a0a6f74d7f619879cff178f1bdef3e9b95b26a8bdce98e66e` |

예제는 [고정 commit](https://github.com/koreainvestment/open-trading-api/commit/277ec0eb7a9b7f63b6807829286c80f36649dad2)의 파일을 Git blob SHA-1·크기·SHA-256으로 대조했다. 공개 상세 JSON은 조회 당시의 원문이며 문서 수정 시각이나 Git commit 시각을 시장 상태 적용일로 취급하지 않는다.

`preflight.json`은 원문 10개 사례·제한 필드 건수·이전 증적의 경로/크기/해시를 보존한다. `source-capture.json`, `specification-capture.json`은 공식 자료를 연결하고, `collection.json`은 미지원 중단과 실제 0회 호출을 기록한다. `verification.json`과 별도 재현 보고서는 네트워크 없이 전체 행·사례·필드 건수·공식 자료 해시와 이전 증적 무변경을 확인한다. 기존 파일은 덮어쓰지 않는다.

```powershell
.\build\kis-stock-eligibility-source-validation-01\observe.ps1 -Mode Replay
```

첫 재현은 `replay-verification.json`을 새로 만든다. 이미 있는 최초·재현 보고서는 덮어쓰지 않으며 다시 실행할 때는 별도 보고서 이름 또는 새 관측 경로가 필요하다. 증적을 보존하려면 `gradlew clean`을 실행하지 않는다.

이번 변경은 검증 문서와 관련 문서의 안내 링크다. 운영 파서·유형 정책·자격 정책·후보 목록·Harness·Risk·Prompt·스케줄·DB·스키마·`.env`·Docker는 변경하지 않았다. 운영 코드 변경이 없어 Gradle 테스트를 재실행하지 않고 별도 오프라인 검증을 수행했다. 기존 고정 종목 모의운영과 독립적인 조사이며 서버를 시작·정지·재배포하지 않았다.

## 후속 실전 조회 실측

별도 [KIS 주식기본조회 실전 응답 검증](kis-stock-basic-info-observation-01.md)은 로컬 실전 조회 키 준비 후 같은 10개 사례를 조회했다. 10건 모두 정상 응답이고 표준코드·시장·그룹·상장일·거래정지·관리종목은 보존 마스터와 일치했다. 응답 `pdno` 형식은 요청 단축코드와 다르고 ETF·정리매매 사례의 주식종류는 빈 값이므로 자동 정규화·자격 승인은 보류한다. 이번 문서의 모의 미지원·실측 미요청·0회 호출 기록은 당시 결과로 유지하며 후속 관측으로 소급 변경하지 않는다.
