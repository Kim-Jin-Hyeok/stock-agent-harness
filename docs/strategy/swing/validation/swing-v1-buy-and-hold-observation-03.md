# SWING_V1 매수 후 보유 비교 관측 결과 03

## 요약

2026-10-01 [확대 관측 결과 02](swing-v1-baseline-observation-02.md)의 원본 입력과 SWING 결과 스냅샷을 보존한 채, 새 매수 후 보유 계산기로 같은 삼성전자 일봉과 609개 평가일을 비교했다. 이번에는 DB, Docker, Spring 애플리케이션과 외부 API를 시작하지 않았다. SWING 수익률은 기존 실행 결과를 사용했고 SWING 전략 자체를 다시 실행하거나 조정하지 않았다.

초기 자금 100% 매수 후 보유의 청산비용 보정 누적 수익률은 **253.58969%**, 10% 배분은 **24.34460%**였다. 기존 SWING 결과는 **31.02649%**다. 아래 MDD는 시가 평가곡선 기준이며 마지막 가정 매도 비용은 곡선에 추가하지 않는다.

| 대상 | 청산비용 보정 누적 수익률 | 시가 평가곡선 MDD | 최종 청산 가정 자산 |
| --- | --- | --- | --- |
| SWING_V1 | 31.02649% | 14.38969185% | 13,102,649원 |
| 동일 종목 최초 100% 배분 | 253.58969% | 46.29044765% | 35,358,969원 |
| 동일 종목 최초 10% 배분 | 24.34460% | 15.52656218% | 12,434,460원 |

SWING 수익률은 100% 보유보다 222.56320%p 낮고, 10% 보유보다 6.68189%p 높았다. SWING MDD는 각각 약 31.90%p와 1.14%p 낮았다. 투자 비중과 진입 시점이 다른 결과이므로 위험이 동일한 비교나 반복 가능한 초과수익으로 해석하지 않는다. 완료 거래 4건 중 1건에 SWING 이익이 집중되었다는 기존 한계도 그대로 남는다.

## 고정 조건

- 후보: `005930` 한 종목, 초기 현금 10,000,000원, 최초 보유 없음.
- 평가 기간: `2024-03-26`부터 `2026-09-28`까지, 기존 SWING과 동일한 평가일·시각 메타데이터 609개.
- 비교 배분: 결과를 보기 전에 정한 100%와 10%. 배분 최적화나 재진입 없음.
- 매수 기준 시가: 첫 평가일 79,700원. 최종 평가 및 청산 기준 시가: 283,500원.
- 비용: `EXAMPLE_UNVERIFIED_V1`, 버전 1. 매수·매도 수수료 각 0.00015, 매도 세금 0.0018, 매수·매도 슬리피지 각 0.001. 실제 계좌 비용으로 검증된 모델이 아니다.
- KOSPI는 기존 같은 평가일 종가 기반 수익률 149.89173368%, MDD 38.63043156%를 참고값으로 유지한다. 동일 종목 시가 비교와는 자산·평가 시각·비용 조건이 다르다.

전체 초기 현금을 수익률 분모로 사용했다. 10% 배분의 분모를 투자금 1,000,000원으로 바꾸지 않았다. 현금 이자와 배당·기업행위는 추가하지 않았다.

## 재현성과 독립 검산

계산 전 원본 파일의 SHA-256이 기존 관측과 같은지 확인했다.

```text
원본 입력:
a31ae2a86be9519fd05e7938fd29afe13f137f64c288b054933136bbb34829a8
원본 SWING 결과:
26a0b8358e3caa6e492af2a64173ec1cb175795f9ee38f55978555cccbcfe4d3
신규 비교 전체 결과 (독립 JVM 2회 일치):
8b57896d020d2031101053019cf3ae68f89fab5116242834bc0dc93dfa7d5885
```

원본 Step의 `BACKTEST_DAILY_OPEN` 판단 근거와 입력 일봉의 시가를 609개 평가일에서 비교했다. 새 Java 계산기를 서로 다른 JVM에서 두 번 실행했고 전체 결과 파일의 해시가 같았다. 시간에 따라 달라지는 실행 시각은 비교 결과에 포함하지 않았다.

PowerShell decimal 계산으로 Java 계산기를 호출하지 않고 7,385개 항목을 검산했으며 불일치는 0개였다. 다음을 확인했다.

- 비용 포함 최대 정수 수량과 그 다음 수량의 예산 초과.
- 매수·매도 체결가, 수수료, 세금, 슬리피지와 정산금액.
- 각 평가일의 날짜·시각, 현금, 고정 수량의 시가 평가와 총자산.
- 최초 현금을 포함한 MDD 금액·비율과 고점·저점일.
- 마지막 평가금액 수익률과 청산비용 보정 순수익·수익률.

금액은 정확히 일치해야 했고 비율 검산 허용 오차는 `1e-12`였다. 재현성과 검산은 계산 일관성을 확인한 것이지 원본 KIS 데이터나 체결 가능성을 독립적으로 확인한 것은 아니다.

구현 후 전체 Gradle 테스트 1,430개가 통과했고 실패·건너뜀은 0개였다. 새 비교 계산·결과 검증, 평가 서비스의 가격·출처·관측 시각 불일치 차단과 수동 Runner 로그를 포함한다. `git diff --check`도 통과했다.

## 증거와 재실행

임시 실행 도구와 전체 결과는 Git에서 제외되는 다음 경로에 있다. 기존 관측 파일은 덮어쓰지 않았다.

```text
build/buy-and-hold-observation/CompareBuyAndHold.java
build/buy-and-hold-observation/run-01.json
build/buy-and-hold-observation/run-02.json
build/buy-and-hold-observation/audit-comparison.ps1
build/buy-and-hold-observation/audit.json
```

기존 원본 스냅샷과 임시 도구가 남아 있다면 다음 명령으로 외부 연결 없이 재실행할 수 있다. `clean`은 `build` 증거를 삭제할 수 있으므로 사용하지 않는다. 클래스패스 준비용 init 파일 역시 이전 관측의 임시 파일이다.

```powershell
.\gradlew.bat -I build/backtest-observation/classpath.init.gradle writeObservationClasspath --console=plain
$classpath = (Get-Content -Raw build/backtest-observation/runtime-classpath.txt).Trim()
java -cp $classpath build/buy-and-hold-observation/CompareBuyAndHold.java build/buy-and-hold-observation/run-01.json
java -cp $classpath build/buy-and-hold-observation/CompareBuyAndHold.java build/buy-and-hold-observation/run-02.json
powershell.exe -NoProfile -File build/buy-and-hold-observation/audit-comparison.ps1
```

위 명령은 신규 비교 파일만 덮어쓴다. 원본 스냅샷이 사라지면 같은 관측의 재현을 주장할 수 없다. 정규 DB 기반 실행과 계약은 [매수 후 보유 비교 문서](../swing-v1-buy-and-hold-comparison.md)를 따른다. 전체 테스트 검증도 별도로 수행한다.

## 판정

같은 종목·평가일·비용의 비교와 계산 검산을 완료했다. 다만 100% 비교는 운영 Risk 한도를 따르지 않는 기회비용 참고이며, 10% 비교도 보유 중 비중과 ATR 위험이 SWING과 같지 않다. 이번 결과로 전략 규칙을 변경하거나 실제 자금을 투입하지 않는다.

이미 관측한 한 종목의 구간이다. 미사용 구간, 다종목, 실제 비용, 데이터 편향·기업행위와 Forward Test 검증은 범위 밖이며 다음 승격 조건으로 남는다.
