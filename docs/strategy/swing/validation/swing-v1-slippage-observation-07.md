| 기간 | 1차 시작 KST / 서비스 소요 시간 | 2차 시작 KST / 서비스 소요 시간 | 전체 JSON 값 | 원본 바이트 해시 |

모든 시각은 2026-10-02다. 소요 시간은 해당 기간의 세 비용 평가 서비스 호출을 합친 시간이며 Spring 시작·점검·JSON 저장은 제외한다. 한 종목 또는 하나의 거래당 소요 시간이 아니다.

입력 전체 SHA-256은 두 실행이 같았다. 요청·원본 OHLCV·지수·전략 설정을 포함한다. 결과는 전체 Step, 판단 근거, 체결, 포트폴리오, 거래·성과·노출 요약, 두 보유 비교와 진단을 포함한다. 실행 시각은 별도 메타데이터에 보존했다.

```text
A inputSha256=34a345457ced232b2fd9d2005a3e089c76b276502c1e9ddccb0153385d87b063
B inputSha256=458dfce9fcc2f86d16d948c3fea532bd0d0f9819ba3f0d19ba7e471880024bd8
C inputSha256=679dd5505d3c4fc64be0ba8643d2a484c3e92991b8916ad8b470eaf8005b504d

A canonicalResultSha256=2ab3771f08c1eb62bf5130b81295aaaef70cdb87a9e122157a56d8c6b23427dc
B canonicalResultSha256=c29d6a401431399c847f74786604f5181e3db8b5c07f8780ce8c724bb6f1caaa
C canonicalResultSha256=3b6011c22fdc3d08ef153ca2810844056015c52112a96751abc4ab2d449b460f
```

C는 JSON 객체 필드 출력 순서 차이로 원본 바이트 해시가 달랐다. 숫자를 `BigDecimal`로 파싱한 전체 재귀 비교 차이는 0개였다. 객체 키만 정렬하고 배열 순서·숫자·`null`을 유지한 정규화 해시는 같았다. 세 비용의 개별 결과도 각각 두 실행 간 값이 같았다. 원본 파일을 정렬하거나 덮어쓰지 않았으며 C의 바이트 단위 재현성까지 통과했다고 주장하지 않는다.

기준 비용의 전체 결과는 관측 05의 두 회차와 비교했다. 당시 없었던 SWING 및 보유 비교의 `exposureSummary`만 대조용 사본에서 제거했다. 그 밖의 모든 결과 값은 같았고 원본 05 입력·결과 파일의 해시도 유지됐다. 기존 결과를 현재 필드 구조로 덮어쓰거나 없는 필드를 0으로 보완하지 않았다.

별도 PowerShell 검산은 Java 계산기를 호출하지 않고 저장 일봉과 비용 모델로 SMA·Wilder ATR, 다음 일봉 시가, 매수 올림·매도 내림 체결 단가, 수수료·세금, 현금·정수 수량·평균 취득가 전이, 완료 거래 손익·Profit Factor·이익 집중, 최종 가정 청산, MDD, 두 보유 비교의 전체 곡선과 노출 다섯 필드를 다시 계산했다. 금액·수량은 일치 여부를, 비율은 `1e-12` 허용 오차를 확인했다. 전체 JSON 재현성 비교는 이 비율 허용 오차를 사용하지 않는다.

총 250,674개 검산 항목에서 불일치는 없었다. 첫 회차의 SWING Step 7,308개, 적용 체결 99개, 완료 거래 42개 및 보유 비교 72개를 확인했다. 이는 같은 시장 표본을 세 비용으로 반복한 계산 건수다. 독립 거래 수나 전략의 통계적 신뢰 수준을 나타내지 않는다. 두 번째 회차는 전체 JSON 대조로 확인했다.

독립 검산 도구의 최초 실행은 JSON에 없는 `runResult.equityCurve`를 참조해 중단됐다. 저장된 `steps[].equitySnapshot`에서 평가곡선을 구성하도록 도구만 수정한 뒤 아홉 검산을 완료했다. 평가 결과나 운영 코드는 바꾸지 않았다. 별도로 초기 Java 소스 실행의 샌드박스 클래스패스 오류는 DB 점검·평가 전 발생했고, 승인된 실행 환경에서 같은 도구로 진행했다.

전체 회귀 테스트는 `./gradlew.bat test --no-daemon --rerun-tasks`로 실제 재실행했다. **1,543개 테스트, 실패·오류·건너뜀 0개**다. `clean`을 실행하지 않아 이전 관측 증거도 보존했다.
